# Canon-ID-register

## Prefixen

- `VF-###` — bewoners
- `VF-ST-###` — verhalen
- `VF-OR-###` — oorsprongsdossiers
- `VF-LOC-###` — locaties
- `VF-OBJ-###` — voorwerpen
- `VF-DEC-###` — formele besluiten indien later nodig

## Regels

- Een ID wordt nooit hergebruikt.
- Een naam kan veranderen; het ID blijft stabiel.
- Verwijderde concepten worden gearchiveerd, niet uit de geschiedenis gewist.
