# Metadata-schema

Aanbevolen minimale metadata voor toekomstige machineleesbare bestanden:

```yaml
id: VF-007
name: Sarah
type: character
status: in-development
creator: Mila
species: rabbit
canon_locked:
  - name
  - creator
  - species
open_canon:
  - appearance
  - clothing
  - age
  - voice
```

## Regel

Machineleesbare metadata mag nooit meer canon bevatten dan de menselijke brondocumenten.
